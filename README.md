# Schemopoint.BPMN_in_1C
"Схемопоинт. Процессы BPMN внутри 1С"  позволяет создавать, рисовать схемы в канонической нотации BPMN 2.0 Загружать схемы из валидного XML BPMN внутрь редактора, сохранять схемы как элементы Справочника процессов. 
Связывать элементы BPMN с объектами 1С. Снимать отчеты о кол-ве элементов или объектов 1С. 

Схему из редактора с поддержкой экспорта BPMN можно загрузить в 1С.
Буквально за пять минут можно:
    - сохранить схему из привычного редактора в формате `.bpmn`;
    - загрузить её в Схемопоинт;
    - визуально проверить результат;
    - сохранить схему в 1С как новый процесс.

Что разработка не делает:

- Не исполняет процессы и не ставит задачи.    
- Не формирует регламентов процессов     
- Не интегрируется с внешними система исполнения задач

## Техническая информация
Платформа разработки 1С: 8.3.27

Совместимость расширения проверена на платформах 8.3.14, 8.3.16, 8.3.20, 8.3.22  
  
Расширение не содержит заимствованных объектов основной конфигурации.
